# GK61 macOS port

Objective: native macOS replacement for the Windows "GK61 Driver" (OemDrv.exe v1.9) for VID 0x32E3 / PID 0x00F7.
Branch: `feat/macos-port`. Delivery: ask-on-risk. Test runner: Swift Testing (`swift test`).

## Specs

- S1. "Necesito un port para de esta aplicacion no hay versiones para macos" — port the GK61_Setup_v_1.9.exe configuration app to macOS.
- S2. Stack: "Native Swift/SwiftUI" (IOKit HID + SwiftUI).
- S3. UI: "Native macOS" — sidebar (Keys / Lighting / Macros / Device), system colors, light/dark mode, SF Symbols, interactive 61-key keyboard.
- S4. Location: "El port dejalo en mis repositories de documentos" → `~/Documents/REPOSITORIES/gk61-macos`.
- S5 (assumption). The port never sends firmware-update, bootloader or flash-erase commands.
- S6. Macros: "Wire up macros" with the "Library + assign" design — the Macros page holds named macros recorded by typing in the app, with editable steps and delays; the Keys inspector assigns a library macro to a key and picks how it repeats; one macro can go on several keys.
- S7. Macro keys survive save and reload: the applied configuration and the macro library persist to JSON without losing macros.
- S8. Test seams (user choice): "Recording → steps", "Saved-format round trip", "macOS key → HID table".
- S9. Arrow mode: "Lo que necesito dentro de la app un macro que me permita cambiar entre las flechas sin apretar el fn y en su modo normal por ejemplo en el rk61 apretando fn + enter pasa a modo de flechas". Design (user choice "Fn+Enter toggle (Recommended)"): the keyboard's Fn layer gets Fn+Enter → F24; the app listens for F24 from the GK61 and toggles a macOS key mapping, scoped to the GK61, that turns / → ↑, RAlt → ←, App → ↓, RCtrl → → and back. Needs the app open; macOS only. Amended (L22): "en el arrow key me debe dejar acceder a las teclas de las flechas apretando fn sin desactivar el modo" — in arrow mode each key and its arrow swap, so Fn + / types / again. Tests at the agreed packet-encoder seam; the IOKit listener and the hidutil mapping are adapters verified by hand.
- S10. Menu bar: user answered "Yes, add menu bar" to "Should GK61 keep running in the menu bar when you close its window?" — closing the window keeps the app running; a menu bar item shows and switches arrow mode, reopens the window and quits.
- S11. Open at login: "sí, que se abra al iniciar sesión".
- S12. Lighting: "necesito que el teclado ilumine esas flechas cuando esta en ese modo tambien cuando se bloquea la teclado de cmd (que originalmente de viene de windows)". Arrow keys: user chose "Custom lighting on toggle (Recommended)" — each toggle writes custom mode 7 with the 4 arrow keys white and the rest dark; turning it off writes the applied effect back. Cmd lock: user chose "GK61 owns the lock (Recommended)" — Fn+LWin sends F23 instead of the firmware lock; GK61 maps Left Win to nothing on the Mac and lights it red, alongside the arrow lights.
- S13. Shortcuts map: "Tambien necesito un mapa de los shortcuts que trae por defecto el teclado para poder cambiar de musica, acciones secundarias etc".
